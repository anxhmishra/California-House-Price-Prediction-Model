# California-House-Price-Model
This serves as my beginner ML project which takes the California House Price Dataset and Uses a XGBoost Regression Model to Predict the median house prices in California based on demographic andn geographic features

| Feature    | Description       |
| ---------- | ----------------- |
| MedInc     | Median Income     |
| HouseAge   | Average House Age |
| AveRooms   | Average Rooms     |
| AveBedrms  | Average Bedrooms  |
| Population | Population        |
| AveOccup   | Average Occupancy |
| Latitude   | Latitude          |
| Longitude  | Longitude         |


Technologies Used:

Python
NumPy
Pandas
Matplotlib
Seaborn
Scikit-Learn
XGBoost
